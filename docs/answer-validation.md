# 第2段階：入力問題の正誤判定

起点は最新main `50b3cdbe9e7eb31dd8cbb926433d36e219f4e756` です。740問＋ボス4問の問題文・ID・正答・選択肢・解説は変更していません。入力対象は基礎300問と従来問題12問のうち、現行の文字数条件を満たす311問です。428問の入試型とボス4問は従来どおり入力モードの対象外です。基礎のb299は正答が長いため対象外のままです。

## 発見した問題

旧処理は全回答へNFKC・全空白除去・小文字化・かな変換を適用し、文字列で比較していました。

- `Mg` と `mg`、`Cu` と `CU`、`20W` と `20w`、`Aa` と `aa` が同一視されました。`Co` と `CO` も同一視されることを合成問題で確認しました。現行の問題バンクにCo・COを正答とする問題があるという意味ではありません。
- b292では実際の誤答候補「すべてAA」「すべてaa」も、入力すると正解と判定されました。
- 数字間の空白を除去し、`2 0J` を `20J` として正解にしていました。
- NFKCによって化学の上付き文字と下付き文字が同じ数字に変わりました。`H²O` と `H₂O` の混同を合成問題で再現しました。
- `0.30A` に対する `0.3A`、`10.0g` に対する `10g` など、値が同じ小数表記を不正解にしていました。
- 確率の `1/4` と `25%`、イオンの組合せの順序変更、キーボードで入力した反応式、`せきずい` と `脊髄` などを認識していませんでした。
- 日本語IMEの確定Enterが、変換中でも回答を送信していました。

## 問題ごとの判定

ルールは問題バンクの外に定義し、問題IDと既存の正答が両方一致する場合にだけ使います。正答を変更したIDや未登録の問題には、NFCと前後空白除去以外は完全一致を適用します。将来の問題へ既存ルールを推測で流用しません。明示的な `acceptedAnswers` も大小文字を区別して引き続き扱えます。

[311問の確認一覧](input-answer-audit.md) に、問題文・正答・判定種別・単位省略の可否・個別別解を記載しました。

| 種別 | 問数 | 条件 |
|---|---:|---|
| 日本語・記号混在文 | 223 | 日本語のかな幅、カタカナ・ひらがな、意味を変えない空白を調整。英字の大小文字と英数字同士の間の空白は保持 |
| 数値＋単位 | 72 | 問題ごとに指定した単位表記のみ。単位省略は設問が単位を指定する場合・個数等に限定 |
| 確率・割合 | 7 | 分数・小数・%の値を正確に比較。%の倍率を保持。日本語の「4分の1」も分数として処理 |
| イオンの組合せ | 4 | 元素記号・電荷を保持し、2つのイオンの順序を区別しない |
| 化学反応式 | 2 | 下付き数字と半角数字、＋と+、→と->などの入力表記を許容。係数と大小文字は保持 |
| 化学反応式の係数 | 2 | 正の整数表記のみ。小数・分数や「個」は許容しない |
| イオンの電荷 | 1 | 符号付き整数。−・－・-の表記差は許容し、符号を保持 |

数値は小数・分数をBigIntの整数比として比較し、浮動小数点の丸めや一律の許容誤差で正解を増やしません。`0.30000000000000004A` を `0.30A` としては受け付けません。近似問題でも新たな丸め幅は導入せず、指定の答えと同じ値・認めた表記を受け付けます。

全角ASCIIは当該ルール内で半角にできますが、大文字・小文字は変えません。NFKCは日本語の半角かなの範囲に限定し、化学式の上付き・下付きや単位の指数へ一律適用しません。数値と単位の間、および反応式の演算子の前後の空白は許容しても、`C O` を `CO` にしたり、`2 0` を `20` にしたりしません。

確認済みの語句別解は、b076のヨウ素溶液、b080・b110・b200の脊髄／せきずい、b202の配偶子の列挙順、b292の全てAa、b251の反応物の列挙順です。これらは各問題の条件から追加し、全問題への同義語変換は行いません。

IME変換中の `isComposing` またはキーコード229のEnterでは送信せず、変換後のEnterまたは回答ボタンで同じ判定関数を呼びます。4択・作図の採点処理は変更していません。

## テスト

すべて合成データと使い捨てブラウザーで実行し、本番サイトや利用者のブラウザープロファイルへ接続しません。既存のGitHub Actionsは新しいテストも自動検出します。

```sh
# 修正前のmainに、新しい25テストを実行（回帰テストの失敗を確認）
RIKA_SOURCE_REF=50b3cdbe9e7eb31dd8cbb926433d36e219f4e756 \
  python3 -m unittest discover -s tests -p test_answer_validation.py -v

# 修正後：入力25件＋既存履歴保護32件
python3 -m unittest discover -s tests -v
```

新しい25テストには、実際の入力画面・送信処理による311問の既存正答と933件の既存誤答候補の確認が含まれます。IMEはブラウザーのキーイベントで再現しており、Chromebook実機での日本語IME操作は別途確認が必要です。

2026-10-29のクラウド環境内での結果:

| 対象 | 成功したテストメソッド | 非成功のテストメソッド |
|---|---:|---:|
| 修正前mainに対する入力25テスト | 4 | 21 |
| 修正後の入力25テスト | 25 | 0 |
| 修正後の既存履歴保護32テスト | 32 | 0 |
| 修正後の合計57テスト | 57 | 0 |

修正前の出力は `Ran 25 tests / FAILED (failures=75)`、修正後は `Ran 57 tests / OK` でした。各メソッド内の複数回答をsubTestで確認するため、75件の失敗は75種類の独立した不具合という意味ではありません。GitHub Actionsの実行結果は別途確認が必要です。

## 互換性と残る制限

- 保存キー・保存形式・問題ID・既存の習熟度・連続学習記録は変更しません。過去の回答や成績を新しい規則で再採点することもありません。誤答履歴には入力された文字列をそのまま残します。
- 以前正解になっていた小文字の元素記号・単位・誤った遺伝子型は、今後の回答では不正解になります。
- 任意のSI単位換算、自由記述の意味理解、化学反応式の自動平衡化、すべての同義語・等価式の認識は実装していません。未登録の妥当な別解が残る可能性があります。確認後に該当IDのルールとテストを追加してください。
- 保存の同時更新・古いキャッシュ等の制限は [第1段階の説明](history-protection.md) のとおりです。
