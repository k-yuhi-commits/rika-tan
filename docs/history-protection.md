# 学習履歴の保護と互換性

## 保持する形式

保存キー `rikaTangoV2` と現行の `schemaVersion: 92` は変更しません。確認した旧版は42・47・56・62です。EXP、ライフ、連続学習日数、最終学習日、回答数、誤答、復習予定、テスト履歴、および未知の問題ID・追加フィールドを保持します。自動同期や別オリジンからの読み取りは追加していません。

- 旧版の用語名をキーにした習熟度は残し、現行の問題ID別キーがない場合だけ補います。ボス問題も対象です。既存のID別習熟度を上書きしません。
- 既存の e135/e136/e137 から e141/e142/e143 への履歴複製を維持します。
- 旧版が同じ用語や `undefined` キーに集約していた習熟度から、元の問題ごとの正確な値は復元できません。元のキーを削除せず、不明な問題へ値を推測して割り当てることはしません。
- 更新前の保存文字列は `rikaTangoV2-preupgrade-v92` にそのまま保持します。既存のバックアップを置き換えません。新規バックアップに失敗した場合は、自動移行による主データの書き換えを停止します。
- 将来版のデータは上書きせず、移行処理も適用せずに書き出せます。

## 保存・読み込み・復元

保存データの構造と、ネストした履歴・数値・習熟度・得点の範囲を検証します。壊れた保存データは主キーに残したまま上書きを停止し、書き出せるようにします。最初に検出した破損文字列の予備コピーも、可能な場合に限り保存します。

取り込み・復元は候補データを別に構築し、検証と移行後に確認します。現在の保存文字列を `rikaTangoV2-preimport-backup` へ保存でき、主データの保存も成功した場合にだけ、メモリ内の状態を置き換えます。主データの保存に失敗した場合は直前のバックアップへのロールバックも試みます。復元時も現在の記録をバックアップするので、直前の取り込み・復元を戻せます。バックアップは1世代の切り替えであり、無制限の履歴ではありません。

壊れた主データがあっても、明示的に有効なJSONを取り込むか有効なバックアップを復元できます。その際も置き換える前の文字列をバックアップします。構造が不正な場合は変更しません。取り込み可能なファイルサイズは従来どおり5MBです。

理由の自己評価が未確定の正解は、回答記録を保存しつつ、習熟度と苦手克服の仮加点を保存しません。自己評価の確定後に加点を保存します。再読み込み・書き出しで仮加点が残らないようにし、未確認の場合は短期復習へ回します。

成績画面の日付と間違いノートの最終日付は、HTMLとして解釈せず表示します。合成JSONを通じたスクリプト実行の回帰テストも含みます。

## 旧版HTMLを変更した理由

全4版は同じ保存キーへ無条件に書き込み、現行データの形式番号も旧形式へ変更していました。現行版だけを修正しても、旧版の起動時の書き込みは防げません。

そのため `rika-tango-v4.2.html`、`rika-tango-v4.7.html`、`rika-tango-v5.6.html`、`rika-tango-v6.2.html` を現行版へ転送します。遷移が完了する前にも旧保存処理が動かないよう、旧スクリプトを非実行形式にしています。旧版内の問題・正答・解説・ボス問題のデータ部分は変更していません。

互換性への影響は、旧URLから現行版を開く動作になることです。旧版UIでの学習は提供しません。既存の旧版履歴は同じオリジンの現行版で移行できます。JavaScriptが無効な場合に備えて現行版へのリンクも置いています。

## 複数タブと残る制限

読み込み時の保存文字列を記録し、各書き込み直前に照合します。別タブの更新や削除を検出すると、そのタブの上書きと新たな回答を停止し、書き出し・再読み込みを案内します。`storage` イベントでも検出します。履歴の自動マージは行いません。

`localStorage` には複数操作のトランザクションや比較交換がありません。厳密に同時の書き込み、バックアップ更新と主データ保存の間のブラウザー強制終了まで完全な排他・原子性を保証するものではありません。完全な対策には、Web LocksやIndexedDB等を使う保存方式への追加設計が必要です。競合時は書き出して保管してから再読み込みしてください。

すでに開かれている未修正の旧版、別途ダウンロード済みの旧版、古いキャッシュのコードへ、この変更を遡って適用することはできません。更新後はそれらを閉じて現行版を再読み込みしてください。ブラウザーの全データ削除、端末故障、ストレージ自体の破損を防ぐ機能でもありません。重要な履歴はJSONで端末外へ保管してください。
